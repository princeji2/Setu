National Identity Registry Architecture & Gateway Interoperability

This application operates with strict domain isolation: dedicated backend, independent PostgreSQL database (aadhaar_portal_db), and parameterized queries. It integrates with the Setu consent gateway via secure service API keys (X-Gateway-Key) and standardized field-level demographic endpoints.
